# Synchronisierung – nächster Schritt

Die derzeitige Vorschau verwendet ausschließlich lokalen Gerätespeicher. Sie ist nicht zwischen Geräten synchronisiert.

Geplant: Supabase Auth für drei getrennte Benutzerkonten, Familiengruppen, Einladungen, Einträge mit Eigentümer und Sichtbarkeit, PostgreSQL Row Level Security und Echtzeitupdates. Kindertermine und Umgangszeiten sind besonders schützenswert. Vor Produktivbetrieb werden die Zugriffskontrollen mit drei Testkonten und unberechtigten Zugriffen getestet. Keine Service-Role-Schlüssel im Browser oder GitHub speichern.
